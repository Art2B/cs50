# CS50
'm following the CS50 class from Harvard. I'm pushing my exercices here for everyone to see.

## Boilerplate
I implemented a boilerplate generator to generate new projects within that folder
* `make build` to create the generator
* `./generate NAME` to generate the folder

## Requirements
* [CS50 lib](https://github.com/cs50/libcs50)
* gcc and anything related to building C
